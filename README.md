# ⚖️ BMI Calculator App  

A simple and interactive **Flutter BMI Calculator App** that helps users calculate their **Body Mass Index (BMI)**.  
The app uses an **API** to calculate BMI values and provides clear results with a simple, user-friendly UI.  

---

## 🚀 Features  
- 📌 Calculate BMI using **API integration**  
- 📌 Input fields for **weight (kg)**, **height (cm)**, **birth date (to calculate age)**, and **gender**  
- 📌 Displays **BMI value** and **health category** (Underweight, Normal, Overweight, Obese)  
- 📌 Clean and minimal user interface  
- 📌 Built with **Flutter & Dart**  

---

## 🛠 Tech Stack  
- **Flutter** – Frontend framework  
- **Dart** – Programming language  
- **API** – For BMI calculation
